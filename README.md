# 🧪 Learning Lab

> A personal laboratory of small projects and experiments — built one
> commit at a time while learning to become a software engineer.

Hi, I'm Rounak Raghuwanshi. I hold an M.Sc in Computer Science and I'm on a
self-taught journey to become a professional software engineer. This
repository is my practice ground.

It is NOT a portfolio. It's a workshop — messy, honest, and always
growing. The polished projects will live in their own repos someday.
This is where they're born.

## 🎯 Purpose

- Learn by building, not just watching tutorials
- Keep every small project and experiment in one place
- Track my progress over time
- Build the daily habit of writing code, committing, and moving forward

## 🧭 How I work in this repo

1. **Every project gets its own folder** with its own `README.md`
   explaining what it does, what I learned, and how to run it.
2. **Folder names use `lowercase-with-dashes`** — no spaces, no capitals.
3. **Number prefixes** (`01-`, `02-`) show the order I learned things,
   not importance.
4. **Each JS project has its own `package.json`.** No shared root package.
5. **Commit daily.** Even small fixes. Progress > perfection.
6. **`99-scratch/` is for throwaway code.** It's allowed to be ugly.
